# Jabra Desktop 0.3.0

This release shows each detected Jabra device's SDK role and USB vendor/product identifier when available. Multiple connected dongles remain independently selectable, and pairing controls are offered only when the Jabra SDK confirms dongle management for that device. The diagnostic probe reports the same role and VID:PID without serial numbers or Bluetooth addresses.

## Hardware checked

- Jabra Link 380 (`0B0E:24C7`) detected as a manageable dongle.
- Jabra Evolve 75 SE (`0B0E:2502`) detected as a headset.
- The Link 380 pairing list was read successfully and returned four entries.
- Pairing, connect and disconnect were previously validated on Link 380 as recorded in `docs/hardware-validation.md`.
- Link 370 and simultaneous use of Link 370 plus Link 380 were not tested for this release.

The hardware table documents only combinations actually tested. Device names, roles, and VID:PID values do not establish compatibility for every hardware or firmware variant.

## Current limits

Battery and firmware fields remain unavailable until the optional Properties SDK module is evaluated in a later release. Device settings, button/LED customization, and non-Jabra device management are not part of this release.

Automated validation: 70 .NET tests. Hardware coverage: CachyOS x86_64, KDE, Jabra SDK 4.9.1.1 and Linux Device Connector 2.1.5; see `docs/hardware-validation.md` for exact checks and untested combinations.
