# Jabra Desktop 0.4.0

Jabra Desktop 0.4.0 adds read-only firmware and battery status for a small,
explicit set of Jabra device identities. Existing discovery,
pairing, connection actions, tray behavior, and German/English UI remain
available.

## Device properties

- Link 380 USB ID `0B0E:24C7`, SDK role Dongle: reads `firmwareVersion`.
- Evolve 75 SE USB ID `0B0E:2502`, SDK role Headset: reads `batteryLevel`.
- Link 370 and other identities do not request properties in this release.

The Evolve-family battery property is documented by Jabra, but the Evolve 75 SE
combination has not been validated on local hardware. The release-time hardware
probe found no attached devices, so neither live property read was tested.
Unavailable, invalid, failed, or timed-out values remain blank/unavailable.
Reads happen once after discovery and when the user requests a refresh; there is
no polling, telemetry subscription, property write, or firmware update.

## Install or upgrade on Arch Linux

Download `jabra-desktop-0.4.0-1-x86_64.pkg.tar.zst` from this release and install
it with:

```bash
sudo pacman -U ./jabra-desktop-0.4.0-1-x86_64.pkg.tar.zst
```

SHA-256: `6d599611c34d16e58ffaf34c4bdd14872cadeec733516ecdf24b89e0a9668ade`.

The package includes the Jabra Properties license file and updated third-party
notices. Existing Jabra terms consent and the Link USB udev rule continue to
apply. See the [README](../../README.md) for source installation and USB setup.

## Verification

The adapter supports only typed firmware strings and integer battery values in
the range 0–100. Property reads are bounded and single-flight per device, and
do not block pairing or discovery. Automated tests cover the capability table,
value parsing, optional module failures, timeout, concurrent reads, removal,
localized UI state, and existing workflows. Hardware reads remain unverified;
see [hardware validation](../hardware-validation.md).
