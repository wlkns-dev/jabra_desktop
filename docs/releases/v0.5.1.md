# Jabra Desktop 0.5.1

The sidebar now shows only endpoints that are currently connected beneath
their dongle. Disconnected but saved devices remain in that dongle's pairing
list. A connected endpoint is no longer duplicated under “Other devices”.

Supported connected headsets can now change their device name from the
endpoint view or its action menu. The name is written to the device's
`bluetoothName` setting, not stored as a local alias. The action appears only
when the SDK reports that this property can be read and written. The dialog is
available in German and English; a newly assigned name may take a reconnect
to appear in Bluetooth searches.

## Download and install

The release includes a self-contained Linux x86_64 build in each package:

- Arch Linux: `jabra-desktop-0.5.1-1-x86_64.pkg.tar.zst` — install with
  `sudo pacman -U ./jabra-desktop-0.5.1-1-x86_64.pkg.tar.zst`.
- Ubuntu/Debian amd64: `jabra-desktop_0.5.1_amd64.deb` — install with
  `sudo apt install ./jabra-desktop_0.5.1_amd64.deb`.

SHA-256 checksums are attached as `SHA256SUMS-0.5.1`:

## Verification and limits

All 144 automated tests passed after merging the changes into `main`. Both
packages were built and inspected on CachyOS; the Ubuntu package was not run
on Ubuntu. A Link 370 with a connected Evolve 75 was used for a live SDK rename
test: writing its existing name succeeded, and an independent read confirmed
the name remained unchanged. The visible app showed the device under its
dongle. Automated Wayland interaction could not complete the dialog, so the
physical Save-button path has not been tested end to end. No saved pairing was
removed. Firmware updates and the settings shown in Jabra Direct screenshots
are not part of this release.

See the [verification report](../verification-0.5.1.md) for details.
