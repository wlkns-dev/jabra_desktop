# Jabra Desktop 0.2.0

This release adds a first-run consent gate for the included Jabra SDK components. The device backend starts only after the user accepts the displayed terms, and declining exits without initializing device access.

The desktop UI and tray menu are available in German and English. The tray menu now includes persistent language and System/Light/Dark appearance choices and shows the app version. The Arch package installs both localized terms files alongside the third-party notices.

## Install on Arch Linux

```bash
curl -fLO https://github.com/wlkns-dev/jabra_desktop/releases/download/v0.2.0/jabra-desktop-0.2.0-1-x86_64.pkg.tar.zst
sudo pacman -U ./jabra-desktop-0.2.0-1-x86_64.pkg.tar.zst
```
