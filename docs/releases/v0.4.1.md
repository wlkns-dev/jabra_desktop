# Jabra Desktop 0.4.1

Jabra Desktop 0.4.1 fixes cancelling a device search that is queued behind an
existing dongle operation. Cancelling such a search now cancels the pending
operation-lock wait, so the scan does not begin later after the user has stopped
it. The regression test covers cancellation both before a scan starts and while
it is active.

Install the Arch package from this release with:

```bash
sudo pacman -U ./jabra-desktop-0.4.1-1-x86_64.pkg.tar.zst
```

An Ubuntu package for amd64 is also provided. On Ubuntu 22.04, 24.04, or
26.04, install the downloaded `.deb` with:

```bash
sudo apt install ./jabra-desktop_0.4.1_amd64.deb
```

The release does not change pairing data stored on the dongle or broaden device
support.
