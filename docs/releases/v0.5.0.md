# Jabra Desktop 0.5.0

Multiple Jabra Link dongles now appear as separate groups. Paired headsets and
speakers are shown beneath the dongle that owns them, including disconnected
devices. Selecting an endpoint shows its connection status and the available
connect, disconnect, and unpair actions. Search and pairing-list controls stay
with the dongle.

Firmware is displayed for supported dongles and endpoints. Battery level is
shown for headsets and speakers when the SDK reports it; dongles do not show a
battery field. Device selection survives periodic refreshes. Errors for one
dongle no longer obscure another dongle's state, and known error messages follow
the selected German or English language.

## Download and install

The release includes a self-contained Linux x86_64 build in each package:

- Arch Linux: `jabra-desktop-0.5.0-1-x86_64.pkg.tar.zst` — install with
  `sudo pacman -U ./jabra-desktop-0.5.0-1-x86_64.pkg.tar.zst`.
- Ubuntu/Debian amd64: `jabra-desktop_0.5.0_amd64.deb` — install with
  `sudo apt install ./jabra-desktop_0.5.0_amd64.deb`.

## Verification and limits

All 134 automated tests passed. On CachyOS/KDE, a Link 370 with a connected
Speak 710 and a Link 380 with a connected Evolve 75 SE were used together.
Both pairing lists and firmware/battery values were read; both endpoints were
disconnected and reconnected, restoring the original connections. Other Jabra
models may work through the SDK but have not all been tested. Real unpairing and
physical dongle removal were not performed to preserve the user's saved
pairings. The Debian package was built and inspected but not run on Ubuntu.

See the [hardware record](../hardware-validation.md) and
[verification report](../verification-0.5.0.md) for details.
